About me

The long version, since you are going to be working with me and not with a CV.

I am a computer engineering graduate of Bolu Abant İzzet Baysal University, 23 years old, living in Bahçelievler, İstanbul. I am currently a student at École 42 İstanbul — a school with no grades, no teachers and no lectures, where the entire curriculum is projects and peer evaluation. It suits me, because it is how I was already learning anyway.

There is a pattern to everything I have built: I go one level lower than I need to. My university final project was a tower defense game, and instead of opening Unity I wrote it in Java and Swing — sprite cutting, the render loop, threading, an enemy AI, and a tile-based map editor, all by hand. This is not stubbornness for its own sake. It means that when something breaks at two in the morning, I am not waiting for a maintainer to answer an issue — I already know where the problem is, because I have been down there.

On the other side of that, I ship. Two Unity games where every model, texture, animation and UI element is mine. A Django portfolio site. A PHP platform with five user roles running on shared hosting. I have worked in software and outside it, and I know that a project ends when someone is actually using it, not when the code compiles.

I enjoy learning new things — genuinely, not as a line on a CV. I work well in a team, I ask questions early rather than guessing, and I would rather tell you a deadline is unrealistic than discover it with you later.

Under the hood

This page was not served by Apache.

Every website runs on a program that listens on a port, reads the browser's request and writes the answer back. Almost everyone rents that program — nginx, Apache, whatever the host provides.

I wrote mine. In C, from an empty file, using nothing but the standard library and POSIX sockets. It parses HTTP/1.1 by hand, serves every image and video on this site, keeps connections alive, and refuses to be talked into handing out files outside its own directory.

I did not do this because it is the practical choice. I did it because after this, nothing about the web is a black box to me.
