Two portfolio sites, built deliberately as opposites. This one is C, no dependencies, no JavaScript framework, everything hand-rolled at the protocol level. That one is Python and Django, leaning hard into what a mature framework gives you for free — and spending the time saved on the front end instead: a live canvas starfield, orbiting skill tags, scroll-triggered reveals and a mood avatar that changes with the section you are reading. Knowing when each approach is the right one is the actual skill.

A framework used properly is not a shortcut

Django's templating, static file pipeline, URL routing and view layer do real work here: the project pages are generated from a single template with a slug-based route, so adding a project means adding a dictionary entry, not a page. The same content renders the listing cards, the detail page, the stats and the gallery.

No database, on purpose

A personal portfolio does not change at runtime, so there is no reason for it to carry models, migrations and a database connection. The content lives in a plain Python module. This is the same instinct as the C server on this site, pointed in the other direction: use exactly as much machinery as the problem needs, and not one layer more.

The front end is where the effort went

A canvas particle field draws a constellation that reacts to the cursor. Skill tags orbit the name on independent timings. Sections reveal themselves on scroll through an IntersectionObserver rather than a scroll-event listener, so the page stays smooth. A small avatar in the corner changes expression depending on which section you are reading — which is the sort of detail nobody asks for and everybody remembers.

Written in Turkish, for a Turkish audience

That site targets local clients and is written in Turkish throughout. This one targets international freelance work and is written in English. Same person, same projects, two different audiences — and the language toggle in the corner of this page exists because I would rather not make you guess which one you are getting.
