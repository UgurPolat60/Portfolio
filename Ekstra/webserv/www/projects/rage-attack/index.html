Unity Game · Solo Project

Rage Attack

One fly, one village, one complete nervous breakdown — a chaos game built on systemic AI rather than scripted set pieces.

  • Unity (URP)
  • C#
  • NavMesh AI
  • New Input System
  • ScriptableObject
  • Coroutine state machines
  • Procedural VFX
  • Runtime-generated UI
  • Custom editor tooling
  • Mixamo rig pipeline
  • TextMeshPro

The player takes the role of a housefly — or RobotFly, unlocked later — and descends on an entire village. Every NPC in the scene runs its own independent stress simulation, escalating through a five-stage rage state machine from mild irritation all the way to arming itself and attacking. The real engineering problem was not the fly. It was making the village feel alive and genuinely out of control.

Nerve management: a five-stage NPC rage FSM

Every character in the village runs its own rage state machine, escalating through five stages: mild irritation, provocation, panic, and finally arming and attacking. There are no staged set pieces in this game. Every fight, every riot, every stampede is a side effect of these independent state machines noticing each other and noticing the player.

Two playable characters, entirely different kits

You start as the agile fly. The heavier RobotFly unlocks based on in-game kill count, and its ability set is different from top to bottom — not a stat multiplier, a different way to play.

XP, card-based upgrades and roguelite progression

Provoking villagers earns XP, which feeds a levelling system that offers card-based ability choices mid-run. The card interface is not a UI package — it is generated entirely in code at runtime.

NavMesh AI and procedural VFX

Villager movement is solved on a NavMesh. Most of the effects — disease spread, panic, retaliation — are not authored in the Shuriken editor but grown procedurally from code, which is what lets them react to a situation nobody scripted in advance.

More than 90 custom editor tools

To build and balance the village inside the scene I wrote over 90 custom Unity Editor tools. On a solo project this turned out to be the highest return investment of the whole build — the tooling mattered as much as the gameplay code did.
