Kitchen Rush

A single-player kitchen simulation built entirely on real-time pressure — developed solo, down to the last texture.

  • Unity (Built-in RP)
  • C#
  • New Input System
  • NUnit
  • Coroutine timing
  • MaterialPropertyBlock
  • Mixamo rig pipeline
  • Custom editor tools
  • TextMeshPro

An Overcooked-inspired single-player kitchen management game. The player runs between stations, cuts ingredients, cooks them, and races to get orders onto the counter before they expire. Built end to end alone in Unity — including every model, texture, animation and UI element, with no asset pack and no third-party tooling anywhere in the project.

The gameplay loop

Order generation, ingredient preparation (cutting and cooking), delivery and scoring form a continuous pressure loop: fifteen seconds between orders, three seconds on the stove — tuned specifically to keep the player permanently in motion and never quite caught up.

Architecture through IInteractable

Six different station types — cutting board, stove, sink and the rest — all share a single IInteractable interface. Adding a new station means writing one class that implements it; the gameplay code never learns the station's concrete type. That is the difference between a game you can extend and a game you rewrite.

Input, movement and animation

Three input actions (Move, Interact, Cut) defined through Unity's new Input System. The character moves on a two-state Animator (Idle / Walking) fed by a Mixamo rig pipeline.

Visual feedback without leaking memory

Highlighting is done with MaterialPropertyBlock rather than instantiating a fresh material every frame — a lightweight layer written to the GPU once, instead of a memory leak that only shows up ten minutes into play. Timings like cooking duration run on coroutines.

Tests and quality

Alongside 16 runtime scripts I wrote 7 NUnit unit tests. This was the project where I started taking a test culture seriously inside a Unity project, rather than treating "it looked fine when I played it" as verification.
